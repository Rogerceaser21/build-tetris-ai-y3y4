✓ Good prompt (one-shot)
Role: Act as an expert React, TypeScript, and Tailwind CSS developer. Your task is to build a fully functional, highly polished, and runtime-stable Tetris game in a single shot. Architecture & Tech Stack: Framework: React (Functional components + Hooks). Logic: Use custom hooks (useTetris, useGameStats, useInterval) to separate game engine logic from the UI. Styling: Tailwind CSS (Utility-first). Animation: motion/react for smooth overlays and grid transitions. Icons: lucide-react. Constraint: Use Zap for Hard Drop and Layers for Hold (do not use 'Shift' or 'Space' icons as they don't exist). Data Integrity & Type Safety (CRITICAL): Define explicit TypeScript interfaces for Tetromino (shape: number[][], color: string), Position (x, y), and GridCell (filled: boolean, color: string). Consistency: Ensure the RANDOM_TETROMINO generator returns a structure that exactly matches the state requirements of activePiece and nextPiece. Defensive Coding: Implement null-checks for activePiece in all movement, rotation, and rendering functions to prevent "cannot read property of null" errors. Layout Structure (CRITICAL CONSTRAINT): Container: Centered on screen, dark background (#050505), full height, overflow hidden. Grid: STRICT 3-column layout. CRITICAL: The layout MUST NOT stack vertically or wrap on standard screens. The Left and Right columns MUST remain strictly to the left and right of the Center game board at all times. Use a responsive flex or grid layout (e.g., flex-row, grid-cols-[minmax(120px,250px)_auto_minmax(120px,250px)]) that scales down the elements to fit the screen width rather than dropping the side panels below the game. Center Column: A 10x20 game board with a glassmorphism border and neon glow. Left Column: A "Hold" piece preview box and a "How to Play" panel with keyboard controls. Right Column: A "Next" piece preview, Score/Rows/Level displays, and Start/Pause/Restart buttons. Styling & Theme: Theme: Modern dark mode with Cyan accents for highlights. Effects: Glassmorphism (backdrop-blur, semi-transparent white borders). Overlays: Use AnimatePresence for "Start Game", "Paused", and "Game Over" screens. Game Mechanics: Pieces: 7 standard Tetrominoes with standard colors. Controls: Movement (Left/Right), Rotation (Up), Soft Drop (Down), Hard Drop (Space), Hold (Shift). Event Handling (CRITICAL): Call e.preventDefault() on all game control keys (Arrow keys, Spacebar, Shift) within the keydown event listener to prevent the browser window from scrolling during active gameplay. Engine: Full collision detection (walls, floor, locked pieces), line clearing logic, and a leveling system that increases drop speed every 10 lines.
~400 words · everything spelled out for the AI

The 4 Steps

Find the "Build Tetris with AI" assignment.

📋 STEP 2 Copy the Prompt

Highlight, then Ctrl+C.

🤖 STEP 3 Open Gemini

Go to aistudio.google.com

🚀 STEP 4 Paste & Build

Paste the prompt. Click Build.

Before you click Build: TOOLS → CANVAS, then switch FAST → PRO.

Wait + Talk

While the AI builds, do a Turn and Talk: "What do you think is happening right now?"

You Do

Wait. Play. Change one thing.

⏳ STAGE 1 Wait for the build

Wait until you see the Play button or the game appears. If something looks broken, raise your hand.

🎮 STAGE 2 Play your game

Make sure it really works. Do the controls move? Do blocks fall? Do rows clear? If not, raise your hand.

🧠 STAGE 3 One change

Turn and Talk: pick ONE thing in the prompt you would change to make YOUR game different.
